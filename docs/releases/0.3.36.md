Everything since 0.3.29. Update every machine: horizontal scrolling now crosses the right way round between macOS and other platforms, and a Mac on 0.3.29 or older still sends or injects it backwards. Hydra updates itself, and your Styx relay needs no update.

### Added

- **`invertScrollX` and `invertScrollY` on a slave.** `true` flips horizontal or vertical scrolling from every master before the slave injects it, whatever either side's platform. They are for taste, or for a device that reports one axis backwards. A master refuses them. The web config and the TUI edit both.

### Changed

- **The `edge` update channel takes only edge prereleases.** It no longer moves on to a full release, even a higher-numbered one. Switching back to `stable` does not downgrade; it waits for the next stable release.

### Fixed

- **Scrolling into a Mac with Apple Silicon is no longer garbled.** Horizontal scrolling arrived corrupted there.
- **Horizontal scrolling between a Mac and Windows or Linux is no longer backwards,** in both directions. Mac to Mac stays as it was.
- **Smooth scrolling from a trackpad reaches macOS and X11 slaves.** Fractions of a notch add up instead of being dropped, so an X11 slave scrolls at all for slow trackpad movement. A leftover fraction is dropped when the cursor leaves, so it never adds a notch later.
- **On Linux, the display no longer freezes for almost a second every three seconds** while a monitor is switched away by a KVM. Hydra no longer makes the X server probe every connector when it checks the screens.
- Scrolling into a Mac carries the held modifiers, so Shift+scroll and Cmd+scroll work as they do locally.
- A trackpad scroll up or left from a Mac master is no longer one unit too large.
