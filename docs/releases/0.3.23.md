### Added

- **Switching monitors from the keyboard.** Hold `Ctrl+Alt+Super` and tap an arrow to move to the next screen that way, on this machine or another: the cursor lands in its middle and the window you last worked in there comes forward. With several screens along that edge, hold a second, perpendicular arrow to pick a third of it (`Up` then `Right` for the right third of the top edge). Rebindable as `switchMonitorUp`, `switchMonitorDown`, `switchMonitorLeft` and `switchMonitorRight`, and offered by the web config.

### Fixed

- **A hotkey pressed while on a Windows or Linux slave no longer opens its Start menu, overview or menu bar.** A modifier held through a hotkey was released there as a bare tap; it is now marked as used.
- **An X11 error no longer ends Hydra.** Xlib's default handler exits the process, so a window closing at the wrong moment, or a hotkey another application already holds, could take Hydra down; the error is now reported and Hydra carries on.

### Changed

- **An empty hotkey list turns that action off.** `"copyFiles": []` now disables the hotkey rather than keeping its default; the web config writes it when a hotkey field says `none`.
- **A chord bound to two actions is warned about at startup.** It still belongs to the first.
- **On an X11 master, a rebound `toggleCursorLock` now works while the cursor is at home.** Only `Ctrl+Alt+Super+L` did before.
