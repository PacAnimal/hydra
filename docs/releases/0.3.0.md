### Breaking

- **The embedded relay is encrypted with TLS, and only TLS.** Machines on 0.3 and machines on 0.2 cannot reach each other through an embedded relay, so update every machine in the setup. Self-update does this on its own, and the machines lose each other until the last one has updated. There are no certificates to set up: each relay makes its own on every start, and a machine trusts it only once the relay has proven it knows the password.
- `embeddedStyx.server` should now say `https://`. An `http://` address still works, over TLS, and logs a warning until you change it.
- `embeddedStyx` pointed at a standalone Styx now needs that server on `https://`, behind a certificate your machines already trust.
