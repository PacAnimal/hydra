### Added

- **Log files stay a fixed size.** A `logFile` is cut down once it reaches `logMaxSize`, 10 MiB unless set: it moves to `hydra.log.1` and a fresh log starts, keeping `logHistory` older files beside it (1 unless set). With `logHistory` at 0 the log is instead trimmed in place, dropping the oldest `logTrimPercent` of it (half unless set). `"logMaxSize": null` lets a log grow as before.
- **`"clipboardSync": "Off"` keeps a machine's clipboard and files to itself.** Set on a master or a slave, it stops clipboard sync and file transfer with every peer in both directions; the file transfer hotkeys say "File transfer is off". Hydra does not touch the clipboard at all while it is off.
