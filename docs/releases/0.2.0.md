## Hydra 0.2.0

Everything since 0.1.0, in one place. Existing installs update themselves; `hydra.conf` needs no changes.

### New

- **`hydra tui`** — a terminal control center for a running Hydra: connection, peers and screens, live logs,
  relay diagnostics, and a form editor for `hydra.conf` that validates before it saves. Works the same on macOS,
  Windows and Linux. `hydra tui --demo` shows it without a daemon.
- **Remote management** — run `hydra pair` on another machine, enter its code in the TUI's Remote tab, and edit
  that peer's config from your own desk, over the encrypted relay.
- **Let machines sleep** — `allowSystemSleep: true` lets the OS put a machine to sleep as usual. Hydra steps off
  the relay first and is back within seconds of waking.
- **Displays that sleep don't drop out** — when a slave's screens power down, it stays connected and the cursor
  you parked there stays put. Moving the mouse wakes it.
- **Configurable hotkeys** — rebind any of them in `hydra.conf`. New: lock every slave at once, plus Pause,
  PrintScreen and Menu as bindable keys.
- **Richer clipboard** — formatted text (HTML and RTF) survives the trip between machines, and
  `clipboardSync: "System"` lets macOS peers use Universal Clipboard instead.

### Better

- Shortcuts work when the master's keyboard layout isn't Latin, and Option+Space works on macOS.
- Typing stays responsive while files are copying between machines.
- Copying files on one machine and pasting on another always pastes the latest copy, never a stale one.
- A dropped network link is noticed and reconnected far sooner.
- Hydra runs at raised priority, so a busy machine doesn't make the cursor lag.
- On Windows, the files beside `hydra.conf` that hold pairing secrets are readable only by you, the service and administrators.
- `--config` is honoured everywhere, including by `--install`, and a mistyped argument is refused instead of
  ignored.
- Third-party relay clients and servers can be built from the published [Styx protocol](https://github.com/PacAnimal/hydra/blob/main/Styx.md).
