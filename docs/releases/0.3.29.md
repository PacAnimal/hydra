Everything since 0.3.21. Update every machine: large clipboards now travel in a form 0.3.21 does not understand, and keypad keys no longer adjust for an older slave. Hydra updates itself, and your Styx relay needs no update.

### Added

- **Switching monitors from the keyboard.** Hold `Ctrl+Alt+Super` and tap an arrow to move to the next screen that way, on this machine or another. The cursor lands in its middle, as visible or hidden as it was where you started, and the window you last worked in there comes forward. When several screens share that edge, hold a second, perpendicular arrow to pick a third of it (`Up` then `Right` for the right third of the top edge). Rebindable as `switchMonitorUp`, `switchMonitorDown`, `switchMonitorLeft` and `switchMonitorRight`, and offered by the web config. A press that finds no screen that way, or one whose machine is away, is logged.
- **`modifierNumLock` for keypad shortcuts on a slave.** On a master profile, `true` makes a keypad key pressed with Super, Control or Alt cross as its digit whatever the master's NumLock says, and `false` as its navigation key. That is for window tiling on `Cmd`+keypad and the like, driven from a master whose NumLock is off. Hotkeys see the key as the setting makes it. The default leaves the keypad alone.
- **Profiles can tell wired networks apart.** Three new conditions: `address` (an IP address of this machine, or a network it is in, such as `"10.20.0.0/16"`), `gatewayMac` (the router's MAC address, which tells apart two networks with the same addressing) and `wired` (a network cable is plugged in). `{ "wired": true, "gatewayMac": "…" }` means docked at that desk. On macOS, the first profile to use `gatewayMac` makes macOS ask to let Hydra onto the local network. The web config and the TUI edit all three.
- The web config edits `hideCursor`, `allowSystemSleep`, `maxMouseHz`, `hotkeys` and `modifierNumLock`.

### Changed

- **Keypad keys cross as themselves.** With NumLock off, the keypad's arrows, Home, End and the rest arrive on a slave as keypad keys (`KP_Left`, not `Left`), and a slave's NumLock is changed only for a keypad key it affects. It goes back to what it was when the cursor leaves. A macOS master's keypad crosses as digits.
- **An empty hotkey list turns that action off.** `"copyFiles": []` disables the hotkey instead of keeping its default, and the web config writes it when a hotkey field says `none`. A chord bound to two actions is warned about at startup, and still belongs to the first.
- **On an X11 master, a rebound `toggleCursorLock` now works while the cursor is on the master's own screens.** Before, only `Ctrl+Alt+Super+L` did.

### Fixed

- **A large clipboard, such as a screenshot, no longer freezes the cursor or typing.** Clipboards over 512 KiB travel in pieces while the cursor and keys keep moving. Until a large clipboard has fully arrived, a paste on the machine receiving it gets nothing, never what was copied before, and an on-screen message says so if it never arrives. The newest copy always wins.
- **On X11, the cursor no longer crosses to another machine while the keys keep typing here.** An open dmenu or window manager menu holds the keyboard, and the cursor used to cross without it. Now the other machine hears nothing until Hydra has the keyboard, and if Hydra never gets it, the cursor comes back after about a second. The cursor does not cross while a key is held.
- On X11, an application slow to answer a clipboard request no longer turns the next copy, an image for instance, into text only.
- On an X11 slave, Shift with the keypad's arrows selects instead of only moving.
- A hotkey pressed while the cursor is on a Windows or Linux slave no longer opens the Start menu, overview or menu bar there.
- An X11 error no longer ends Hydra. A window closing at the wrong moment, or a hotkey another application already holds, could take it down.
- The web config reads `accelerateMouseWheel` back when importing a config.
